# 🌈 STRETCHICORN 🦄

### **STRETCH · SNAP · SHUCK.**

**Stretchicorn** is a 13KB desktop arcade-action game where you control one enchanted unicorn from both ends.

`WASD` moves the vulnerable **heart/body**.  
`Mouse / Arrow Keys` aim the safe **head and horn**.

Pull them apart to stretch the rainbow and build tension, then `Click / Space` to unleash a **Rainbow Snap**.

> **Only the body can take damage. Your horn, rainbow, and momentum are weapons.**

## 🌽 13 TRIALS. ONE VERY ANGRY CORN ARMY.

Stretchicorn is about turning danger into opportunity.

**Stretch** away from the horn to build charge.  
**Aim** the safe end of the unicorn into places the vulnerable body should never go.  
**Snap** back through enemies, projectiles, pickups, and escape routes.

Gold kernels are opportunities: **graze** them for charge or **parry** them with the horn and send them flying back.

Cyan attacks are different. They **cannot be parried**. Get out of the way.

Recharge and attack again quickly enough to create a **Double Rainbow**, giving your next Snap more power, more reach, and a brief moment of invincibility.

Power-ups can restore health, block a hit, boost movement, strengthen your next Snap, or amplify the Style earned from an aggressive run.

**Style** rewards more than simply surviving. Close dodges, precision counters, strong charged attacks, long chains, and risky play all push your score higher.

The deeper you go, the more the game asks you to juggle these ideas at once.

**Protect the heart. Throw the horn into danger. Make the rainbow do the work.**

## 🎮 EVERYTHING FITS IN 13KB

The complete competition build is **13,304 / 13,312 bytes**.

Everything runs inside **one self-contained HTML file**.

All graphics are generated at runtime with **Canvas**. The reactive arcade-EDM soundtrack and combat sounds are synthesized in real time with **Web Audio**.

**0 image files · 0 audio files · 0 web fonts · 0 runtime libraries · 0 network dependencies**
